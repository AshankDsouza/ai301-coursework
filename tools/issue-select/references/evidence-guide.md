# Evidence guide: where first-issue signals live on GitHub

Use the issue bundle's repo-facts block in eval mode. In live mode, gather the
same facts from the repository's commits, releases, issue sidebar, issue
thread, and contributor documentation.

- **Maintainer activity:** inspect recent default-branch commit dates and
  authors, plus maintainer first-response timing on recently updated issues.
- **Repository use:** inspect archived status, latest release, and most recent
  push.
- **Newcomer scope:** read the full issue body and comments for a single
  implementable request, settled design, and bounded affected area.
- **Availability:** inspect assignees, linked pull requests, and recent claim
  comments. Apply the scoped classroom house rule for Path Review live mode.
- **Contribution policy:** read `CONTRIBUTING.md`, linked contributor docs, and
  any AI policy. An explicit AI ban fails the check; disclosure, testing, and
  understanding requirements do not.
